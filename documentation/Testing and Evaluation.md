5. Testing and Evaluation
5.1 Evaluation Method
The wireframes were first reviewed by an expert check of the Dashboard, Find Activities, Education Level and Activities screens against WCAG 2.2 AA and the low-resource constraints. The prototype was then evaluated using task-based evaluation with  consenting adult classmates or simulated stakeholders, labelled P1 to Pn. No names, contact information, photographs, learner information or other sensitive participant information were collected.
5.2 Evaluation Tasks
Task 1 - Find an Activity: Find an activity suitable for a specified level, topic and duration.
Task 2 - Save and Start: Save the activity for offline use and start the session.
Task 3 - Offline Recovery: Continue using the saved activity after connectivity becomes unavailable.
5.3 Findings
Finding	Priority	Evidence
No offline, failure or recovery screen exists, so offline status and data loss cannot be understood.	High	Expert review;
White text on the orange "Show Activities" button has low contrast (estimated 3.3:1).	High	Expert review; 
Activity cards do not show pack size or whether an activity is saved on the device.	High	Expert review; 
The back control is a small icon with no text label.	Medium	Expert review; 
Education levels are listed out of order (Upper Primary before Lower Primary).	Low	Expert review
5.4 Prototype Changes
Change 1 - Offline Status: An offline banner, a download-failed screen with retry, and a pending-sync state were added, using both an icon and text. This explains what happened and what is still available. 
Change 2 - Activity Information: Each activity card now shows the pack size and a text status such as "Saved on this device", so users know what uses data and what works offline. 
Change 3 - Button and Back Control: The orange button colour was changed to reach 4.5:1 contrast, and the back control was enlarged and given the accessible name "Back". 
5.5 Evaluation Limitations
The evaluation used a small number of adult participants in a controlled setting. It therefore provides early design feedback rather than evidence from deployment in a real school environment. The expert review was done from screenshots, so contrast values are estimates and no assistive-technology testing was included.
